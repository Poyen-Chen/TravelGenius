# 第六階段圖卡規格與素材記錄

2026-09-25，PD-043；雙欄圖卡已選定，候選待驗收。不是整份目錄已完成逐項繪圖。

## 行為與基本設計

- 第 2 張實際展示圖為目標：奶油色／橘色主題、雙欄、物品圖片、名稱與數量、左上勾選、右上操作。App 使用原生字體與 SF Symbols；PWA 沿用既有字體及圖示庫。
- 保留文字模式。App 初始仍為文字；選擇以 `packmon.packing.images` 保存在此裝置。PWA 保留既有 view 設定，不修改使用者預設。
- 圖片模式不重建／複製物品，不改 ID、原因、数量、常備、排除或推薦規則。App 圖卡數量按鈕開草稿，儲存才套用；取消不更改；範圍 1–99。儲存失敗只還原該次數量，不 rollback 其他資料。
- App 兩欄，無障礙大字一欄；PWA 手機兩欄，小於 350px 一欄，寬桌機三欄。名稱可換行，不以圖片代替名稱。
- 自訂／無對應／缺失資產顯示分類圖示，不是錯誤推測的商品；勾選、数量、常備、移除照常。未新增假物品填滿最後一格。
- 圖卡不按推薦原因切割成多個稀疏網格。App 的原因可在數量編輯中查看；文字模式仍按原因分組。PWA 圖卡保留編輯／常備與分包操作。
- 精簡進度保留項目數；App 保存的天氣可展開，PWA 估重／分包可展開。建議補入與其原清單維持文字模式，避免破壞第五階段的採納流程。
- 不改根導覽、行程設定、資料同步及 PWA 既有 3D。

## 驗收與界線

- 第一批圖像只涵蓋以上範圍；完整其餘目錄繪圖仍未交付，不可宣稱全目錄都有圖片。
- 自動檢查：對應、未知／自訂／複本不誤配、組合與單物品不同、素材存在、兩端一致及離線預載；原有推薦回歸仍須通過。
- 人工：切換模式、勾選一致、數量儲存／取消、缺圖自訂品、移除取消與確認、重開、斷網、長名稱／大字。
- 資料儲存耗盡及實機 VoiceOver 若未實測，須在交付說明；測試 fixture 使用獨立來源與記憶體 App，不能植入正常資料。
