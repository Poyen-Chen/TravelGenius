## 人工驗收清單

1. 建立近期行程：國家／地區 → 城市 → 日期 → 天氣 → 清單確認；取消一件推薦、加入一件自訂，完成後直接進入該行程，選擇保留。
2. 打包與圖片：勾選、修改數量、取消一次編輯、切換文字／圖片；同一物品狀態一致，未有素材的物品仍可操作。此輪不驗收最終畫風。
3. 更新建議：先手動改數量、勾選及排除，再開啟更新建議；只加入選取項目，取消不變更，重複操作不重複加入。
4. 個人需求與常備：新設定帶入新行程，不重算舊行程；常備移除與當趟物品移除範圍不同，取消确认不刪除。
5. 關閉重開：行程、勾選、數量、自訂品與建立時天氣仍保留；既有行程可開啟。
6. 離線：先載入 PWA；斷網後重開、操作既有清單，再建立遠期行程，應明示季節參考而非捏造預報。恢復連線後能正常查詢。
