## 起點與範圍

- 起點：`packmon-ios-stage-05-accepted`，驗收提交 `d1b45832f1c345d209b5fa933b286c60266c774c`；分支 `codex/ios-06-visual-list`。

- App 目前尚無物品圖庫。PWA 已有文字／圖卡切換，但圖卡主要使用分類圖示，尚非逐項物品圖片；適用的圖像與資訊設計須同步，容許響應式排列差異。
- 不做 3D、資料同步、圖片上傳、自動搜尋或線上 AI 生圖服務；不改推薦與原物品資料。

## 分段執行與人工關卡

### 6A：先審小樣

1. 盤點 TravelGenius ItemImages 的可用性、來源與授權，不因已有檔案就推定可商用。
2. 建議先取護照、換洗衣物、充電線、防曬乳、雨傘五種，覆蓋不同外形與分類；準備統一風格及未知／自訂物品備援。
3. 呈現「縮圖列表」與「雙欄圖卡」的少量實際畫面小樣，保留名稱、數量、勾選，沿用 Structure C 主題。
4. 人工選定圖片風格、排列與預設顯示方式後，才製作全套。以上是待審提案，不代表使用者已選定。

### 6B：整合後驗收

- 使用穩定 catalog ID 對應素材；缺圖有明確備援，不靠任意名稱猜出誤導性圖片。
- 視覺／文字呈現共用原有物品及操作，不複製另一份清單；切換不影響數量、勾選、常備與刪除。
- 記錄每份素材的來源、製作方式、使用條件與檔名對應；體積與載入效能納入檢查。
- App 為主，PWA 適用部分使用相同素材與基本設計，再發布 Site 供比較。
- 工程檢查：對應完整性、缺圖、離線、切換後狀態一致、小螢幕及無障礙標籤。
- 人工驗收：圖片易辨識、名稱不截斷重要內容、數量／勾選易操作、自訂物品可用、離線與重開正常。

本階段未完成前不進第七階段。人工通過後依固定流程提交驗收紀錄、推送及建立 accepted tag。
